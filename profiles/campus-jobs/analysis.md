# Evaluation goal

Evaluate whether a campus recruiting posting is a good match for an undergraduate Software Engineering student who wants to work on AI Agent development.

# Scoring rubric

- **9-10: Strong match.** The role is explicitly about AI Agent development, for example Agent frameworks, tool use, planning, memory, MCP, multi-agent systems, or Agent product engineering. It accepts undergraduates (本科 or 学历不限), and accepts software engineering, computer science, or related majors. A 2026 or 2027 graduation cohort is a plus.
- **7-8: Good match.** AI or LLM application and algorithm role closely related to Agents. Undergraduate-eligible or major unspecified, with only minor gaps in cohort or direction.
- **5-6: Possible match.** General software engineering or LLM role with some Agent exposure. Undergraduate-eligible but the direction is indirect, or the direction matches but the posting is vague.
- **3-4: Weak match.** Requires a master's or PhD, targets a different cohort, or is an AI role with little connection to Agents.
- **0-2: Not a match.** Experienced hire, internship, non-technical role, unrelated domain, or spam.

# Evaluation guidance

Read the degree requirement carefully: "本科及以上" includes undergraduates; "硕士及以上" and "博士" exclude them. If the posting does not state a degree requirement, do not reject it, but lower confidence. Prefer postings that name Agent, LLM application, or intelligent assistant work in the title or requirements. Use three to five specific tags such as `agent`, `llm`, `本科可投`, `2027届`.
